Supported Vulnerabilities

SQL Injection (SQLi)

Scans endpoints and forms for database injection flaws that could allow attackers to view, modify, or delete backend data.

  • Error-Based SQLi Detection
  • Time-Based Blind SQLi Detection
  • Tests URL parameters and form inputs

Cross-Site Scripting (XSS)

Detects reflected XSS vulnerabilities by injecting various scripts into application inputs to see if they are unsafely rendered.

  • Reflected XSS Detection
  • Context-aware payload injection
  • Evaluates raw HTML and attribute contexts

Insecure Direct Object Reference

Automatically identifies ID-like parameters and attempts horizontal privilege escalation by accessing unauthenticated objects.

  • Automated ID extraction
  • Baseline deviation analysis
  • Checks for missing authorization
